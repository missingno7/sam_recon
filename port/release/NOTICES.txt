Secret Agent is the original Apogee game (1992). This package is a modern SDL3
port built from the sam_recon historical source reconstruction. Original game
data remains separate and is not included or licensed by this package.

GNU Unifont contributors; modified for sam_recon. It is distributed under
SIL Open Font License 1.1. Full source notices and license: LICENSE-FONTS.txt.
https://unifoundry.com/unifont/

No IBM ROM font or original game data is embedded in the launcher source.
